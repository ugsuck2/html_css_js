1. 클라이언트(client)
서버에게 서비스를 요청하고 그 결과를 받아 사용자에게 보여주는 소프트웨어 또는 하드웨어
예를 들어 크롬 웨일브라우저 사파리 엣지 등이 있다.
클라이언트가 서버로부터 결과를 보여주는 과정
1 요청(Request)보내고 
2 서버와 통신(HTTP)
3 받은 결과값 랜더링, 화면표시
4 사용자 입력처리 및 프론트엔드 로직수행 : 사이트 내 사용자가 버튼을 클릭했을때 간단한 유용성 검사를
하거나, 화면의 움직임(애니메이션) 처리하는 등 브라우저 환경에서 직접 실행되는 코드를 처리


2. 서버(server)
클라이언트의 요청을 받아 그에 맞는 데이터나 서비스를 처리해서 보내주는 컴퓨터 시스템(하드웨어)
또는 그 역할을 하는 프로그램(소프트웨어)
보통 웹 상의 서버는 24시간 꺼지지 않고 인터넷에 연결되어 강력한 성능을 내는 거대한 
데이터 센터의 컴퓨터들을 의미
서버가 일하는 과정
1 요청(Request) 수신
2 데이터 처리 및 비즈니스 로직 수행 : 클라이언트가 보낸 데이터가 올바른지 확인하거나,
 사용자가 요청한 작업을 처리함
3 데이터베이스(DB)와의 상호작용
웹사이트에 필요한 회원 정보, 게시글, 상품 목록 등 방대한 데이터를 안전하게 저장하고 있는
 데이터베이스에 접근하여 필요한 데이터를 가져오거나 수정합니다.
4 응답(Response) 보내기
처리완료된 결과물(html, CSS, 자바스크립트 파일이나 JSON 같은 데이터)를 클라이언트에 보냄


3. ip주소
IP 주소(Internet Protocol Address)는 쉽게 말해 "인터넷 세상 속 컴퓨터의 집 주소"다.
기기식별과 위치지정 및 라우팅
IPv4 (아이피브이포)
가장 널리 쓰이고 익숙한 형태
0.0.0.0부터 255.255.255.255까지의 숫자를 점(.)으로 구분하여 4자리로 표현
예시: 192.168.0.1 또는 8.8.8.8 (구글 DNS 서버 주소)
IPv6 (아이피브이시스)
IPv4의 주소 부족 문제를 해결하기 위해 만든 차세대 IP 주소
콜론(:)으로 구분하며 훨씬 더 길고 복잡한 형태
예시: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
공인ip와 사설ip
공인ip :  인터넷진흥원에서(kt lg skt) 부여해주는 전 세계에서 하나뿐인 ip주소
사설ip : 집이나 회사 내부에서 공유기(Wi-Fi)를 통해 연결된 
기기들끼리(내 컴퓨터, 스마트폰, 프린터 등) 나누어 쓰는 가상의 주소

4. 포트번호
포트 번호(Port Number)는 쉽게 말해 "컴퓨터(서버) 안에서 어떤 프로그램에게
데이터 전달해야 할지 알려주는 문(Door) 번호"
1 포트 번호의 특징
숫자 범위: 포트 번호는 0번부터 65535번까지 총 65,536개가 있다.
IP 주소와의 관계: IP 주소가 건물의 주소라면, 포트 번호는 그 건물 안의 호수(또는 문 번호)에 해당한다.
사용 형태: 보통 웹 주소 뒤에 콜론(:)과 함께 붙어 있는 숫자가 바로 포트 번호다.
0번부터 1023번까지의 포트는 전 세계적으로 약속된 주요 서비스용 번호로 미리 지정되어 있다. 
우리가 평소에 주소창에 포트 번호를 따로 적지 않아도 접속되는 이유는 브라우저가 
이 기본 포트 번호를 자동으로 연결해 주기 때문이다.

5. URL
URL(Uniform Resource Locator)은 쉽게 말해 "인터넷 세상에 있는 자원의 정확한 위치를 알려주는 웹 주소"다.
IP 주소가 전 세계 컴퓨터들의 '집 주소(동/호수)'라면,
포트 번호가 집 안의 '방 번호'이고,
URL은 그 방 안에 있는 '책상 서랍 속 특정 파일의 정확한 이름과 위치'를 가리킨다.
URL의 구조
1 프로토콜(Protocol) - https://
컴퓨터와 컴퓨터가 통신할 때 어떤 규칙(약속)을 따를 것인가를 나타낸다.
웹사이트에서는 주로 http(일반) 또는 https(보안이 강화됨)를 사용한다.
2 도메인이름(Domain Name)
사람이 이해하기 쉬운 영어로 된 서버의 주소(실제로는 숫자로 된 IP 주소로 변환되어 찾아간다.)
3 포트번호 (Port Number) - :443
앞서 공부한 그 포트 번호,  https의 기본 포트는 443번이라서 평소에는 주소창에 생략되어 보인다.
4 경로 (Path) - /blog/index.html
서버 안에서 원하는 파일이나 폴더가 실제로 저장되어 있는 물리적/논리적인 위치
5 쿼리 스트링 / 해시 (Query String & Hash) - ?page=1#section2
쿼리(? 뒤): 서버에 추가로 전달하는 데이터(예: 1페이지를 보여줘 등)
해시(# 뒤): 웹페이지 안에서 특정 위치(특정 목차나 문단)로 바로 이동하게 해주는 책갈피 역할

6.웹 브라우저
우리가 인터넷을 사용할 때 가장 흔하게 접하는 프로그램 이지만 , 
그 내부 동작은 클라이언트-서버 구조와 IP 주소, 포트 번호, URL이라는 핵심 개념들이 유기적으로 맞물려 돌아가는 정교한 시스템이다.
1. 웹 브라우저의 역할: 클라이언트 (Client)
특징: 사용자의 요청을 받아 서버로 보내고, 서버가 보내준 결과물(HTML, CSS, 이미지 등)을 해석(Rendering)해서 
화면에 보기 좋은 웹페이지로 보여주는 클라이언트(고객) 역할을 한다.
2. IP 주소 (Internet Protocol Address): 서버의 위치
특징: 인터넷상에 연결된 수많은 컴퓨터(서버) 중 특정 컴퓨터를 찾아내기 위한 고유한 주소.
3. 포트 번호 (Port Number): 서버 내의 도착지 문
특징: 하나의 서버 컴퓨터 안에서는 여러 개의 프로그램(웹 서버, 데이터베이스, 이메일 서버 등)이 동시에 실행될 수 있다.
 IP 주소가 건물 주소라면, 포트 번호는 건물 안에서 찾아가야 할 '특정 부서(문)'의 번호
4. URL (Uniform Resource Locator): 웹 자원의 전체 주소
특징: 인터넷상에 있는 특정 정보(웹페이지, 이미지, 동영상 등)의 정확한 위치와 접근 방법을 나타내는 표준 주소 체계.
윗 개념들이 브라우저에서 작동하는 과정
1 사용자가 웹 브라우저 주소창에 URL을 입력

2 브라우저는 URL에 포함된 도메인을 IP 주소로 바꾸고, 정해진 포트 번호(HTTPS는 443)를 이용해 해당 서버로 네트워크 요청(클라이언트의 요청)을 전송

3 서버는 해당 IP와 포트에서 요청을 받아 데이터를 찾은 뒤, 브라우저에게 응답을 전송

4 웹 브라우저는 그 데이터를 받아 화면에 출력
