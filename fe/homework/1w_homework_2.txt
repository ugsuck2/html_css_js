HTML
HTML(HyperText Markup Language)은 웹페이지를 만들기 위해 사용하는 가장 기초적이고 필수적인 마크업 언어
웹 브라우저가 화면에 보여주는 모든 텍스트, 이미지, 버튼 등의 뼈대를 구성하는 역할을 담당

태그(tag)

h1 ~ h6 : 제목
p : 문단
div : 영역 구분
span : 인라인 영역
a : 링크
img : 이미지

목록
ul : 순서가 없는 목록
     브라우저에서 기본적으로 각 항목 앞에 동그란 점이 붙어 나타난다.
     
ol : 순서가 있는 목록
     항목들의 순서나 등수가 중요한 목록을 만들 때 사용
li : 목록의 항목
    ul이나 ol 내부에서 실제 각각의 내용을 감싸는 태그
   <li> 단독으로는 쓰이지 않고, 반드시 <ul>이나 <ol>의 자식 요소로 사용



입력 및 버튼
input : 사용자 입력
         사용자로부터 다양한 형태의 데이터를 입력받는 칸을 만든다. 닫는 태그가 없는 단독 태그
         type 속성을 무엇으로 지정하느냐에 따라 모양과 기능이 완전히 바뀐다.
         type="text": 일반적인 한 줄 텍스트 입력 칸 (예: 이름, 아이디)
         type="password": 입력한 내용이 동그라미(점)나 별표로 가려지는 비밀번호 입력 칸
         type="checkbox": 여러 개 중복 선택이 가능한 체크박스
         type="radio": 여러 개 중 하나만 선택할 수 있는 라디오 버튼
         type="submit": 폼 안의 데이터를 서버로 제출하는 버튼
         
button : 버튼
           사용자가 마우스로 클릭할 수 있는 버튼을 만든다.
           type속성의 종류 
           type="submit": 클릭 시 연결된 <form>의 데이터를 서버로 제출 (생략 시 기본값)
           type="reset": 입력한 내용을 모두 초기화
           type="button": 특별한 기능이 없는 순수한 버튼 (자바스크립트와 연동해 특정 동작을 실행할 때 주로 사용)
           

form : 입력 양식
         사용자가 입력한 데이터(이메일, 비밀번호, 검색어 등)를 모아서 서버로 전송하기 위한 구역(영역)을 설정
        주요속성 - action : 데이터를 전달받아 처리할 서버의 주소(URL)를 지정
                      method : 데이터를 어떤 방식으로 보낼지 결정
                      GET : 주소창에 데이터가 노출되는 방식
                      POST : 데이터가 주소창에 노출되지 않고 안전하게 숨겨져서 전송되는 방식

표(Table)
table : 표 전체 테두리
tr : 표의 행 가로줄
     줄 바꿈
th : 표의 제목 셀
     가로줄 안에서 제목이나 항목의 이름이 들어가는 칸
     브라우저에서 기본적으로 굵은 글씨와 가운데 정렬로 표시    
td : 표의 데이터 셀
     가로줄 안에서 실제 내용(값)이 들어가는 일반적인 칸
     왼쪽 정렬로 표시

CSS
HTML이 알맹이(텍스트, 이미지, 표 등)를 만드는 '재료와 구조'라면, CSS는 그 재료들을 보기 좋고 매력적으로 포장하는 '디자이너' 역할
현대 웹 개발에서는 뼈대(HTML)와 디자인(CSS)을 엄격히 분리해서 코드를 작성하는 것이 원칙

color : 색 지정

background-color : 배경색 지정

width / height : 폭과 높이 지정

margin : 해당요소와 다른 요소 사이의 거리를 조절
방향 설정: 위, 아래, 왼쪽, 오른쪽 네 방향의 여백을 각각 따로 줄 수도 있고, 한 번에 묶어서 줄 수도 있다.
margin은 시계 방향(위  오른쪽  아래  왼쪽) 순서로 값을 지정
ex) margin: 10px 20px 30px 40px;
    margin: 20px 40px; /* 위/아래는 20px, 왼쪽/오른쪽은 40px */
    margin: 15px; /* 모든 방향에 15px 여백 */
    실무에서 자주 쓰는 특별한 기술: 가운데 정렬 (margin: auto)
        
padding : 요소의 안쪽 여백을 만들어주는 속성
             상자(div, 버튼, 카드 등)의 테두리(Border)와 실제 내용물(텍스트나 이미지 등) 사이의 간격을 넓혀줄 때 사용
             margin 과 같은 방식으로 값을 설정

border : 요소의 테두리(선)를 지정해 주는 속성, margin과 padding과 함께 쓰인다.
           보통  두께(Thickness), 종류(Style), 색상(Color)을 한 번에 모아서 작성
ex) 
selector {
  border: 2px solid black;
}

font-size : 글자 크기 지정

display : 가장 강력한 속성

display: bolck;
화면의 가로 줄 전체(100%)를 혼자서 꽉 채운다.
뒤에 오는 요소들은 무조건 다음줄로 밀림
대표적인 태그: <div>, <p>, <h1> ~ <h6>, <ul>, <li> 등

display: inline;
줄바꿈을 하지 않고, 글자처럼 텍스트 흐름에 맞춰 옆으로 나란히 배치
크기조절이 불가하다 오직 좌우 여백과 글자 크기에만 반응
대표적인 태그: <span>, <a>, <strong> 등

display: none; (화면에서 숨기기)
해당 요소를 화면에서 아예 보이지 않게 감추고, 차지하던 공간까지 완전히 없애버림

display: flex;
요소들을 가로로 정렬하거나, 세로로 정렬하거나, 가운데로 척척 몰아주는 등 1차원 정렬(한 줄 정렬)을 
아주 쉽고 스마트하게 해주는 레이아웃 방식

display: grid;
가로와 세로를 바둑판(표)처럼 엮어서 2차원 레이아웃(행과 열 동시에 제어)을 짤 때 사용하는 강력한 속성
